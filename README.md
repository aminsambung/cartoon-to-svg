# Cartoon to SVG

Aplikasi Android untuk mengubah
gambar PNG dan JPG menjadi SVG.

## Fitur
- Memilih gambar dari galeri
- Mengubah gambar menjadi hitam putih
- Membuat gambar untuk mewarnai
- Mengonversi gambar menjadi SVG
- Menyimpan hasil SVG
- Mendukung penggunaan offline

## Platform
Android

## Bahasa
Kotlin
